# 2026-10-18: Arranque del frontend

Objetivo: crear el repositorio `servibox-frontend` con el shell de la aplicacion, el login
contra el backend y los tokens del manual de estilos ServiBox v1.0. Rama
`feat/1-project-scaffold`.

## Hecho

* Repositorio nuevo, hermano de `servibox-backend`. `main` con solo el `.gitignore`
  ("chore: initial commit"), publicado en GitHub.
* Vite, React, TypeScript estricto, Tailwind CSS v4, React Router, TanStack Query,
  lucide-react, fuentes con `@fontsource`, Vitest y Testing Library. Detalle en
  [01-ARCHITECTURE.md](../01-ARCHITECTURE.md).
* Tokens del manual en `src/styles/tokens.css`, con las escalas por defecto de Tailwind
  vaciadas. Ver Tokens visuales en [02-CONVENTIONS.md](../02-CONVENTIONS.md).
* Shell: barra lateral con wordmark provisional y siete items, barra superior con usuario
  y Salir, paginas vacias por ruta privada.
* Cliente API con `ApiError` y cierre de sesion en 401; proxy de Vite a
  `http://localhost:8080`.
* Login con Serviteca, Usuario y Contrasena segun la captura del manual; alerta en 401.
  Placeholders "Proximamente" para recuperar contrasena y crear cuenta.
* Componentes: `Button`, `TextField`, `Alert`.
* Decisiones registradas en [03-DECISIONS.md](../03-DECISIONS.md): proxy sin CORS, token
  en `sessionStorage`, tokens como unica fuente visual, menu lateral, paginacion en el
  cliente, IVA como total menos subtotal, medio de pago segun el tipo de cuenta.

## Verificacion

* `npm run build` y `npm run lint` sin errores ni advertencias.
* 12 pruebas con Vitest: cliente API (4), guard de rutas privadas (5) y formulario de
  login (3).
* Prueba real con el backend en perfil `dev` y `npm run dev`: login de `demo` / `admin` por
  el proxy devuelve 200 con token; una ruta privada sin token devuelve 401.
